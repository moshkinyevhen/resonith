## Accepted implementation contract

The final gate contains four separately visible authorities:

1. an independent Python arbitrary-precision generator/oracle that emits the
   frozen JSONL and expected statuses, paths, entries, reports, event ledgers,
   and fingerprints without calling native code;
2. a native v2/v3 ABI and transaction runner that consumes that JSONL;
3. a CUDA runner that executes the identical 10,000 cases on each frozen tile;
4. a comparator that requires exact twice-run and cross-toolchain semantic
   hashes while retaining raw artifacts and SHA-256 inventories.

The successful native publication tail must execute in this order:

1. finish all staging, fingerprints, resource-health checks, cleanup
   reservations, and final report construction;
2. reserve the complete payload budget while the one report token is already
   reserved;
3. consume `payload_count + 1` commit tokens in one checked operation;
4. synchronize the final ledger;
5. copy trivially-copyable disjoint path, entry, and report objects with no
   remaining branch, allocation, ledger call, or reachable exception.

Compile-time assertions must prove trivial/no-throw copy properties. A
post-return cleanup test must prove that PMR destruction cannot fail or alter
the already published event totals.

## Required quantitative gate

Admission requires all of the following:

- exact frozen case-manifest hash;
- every observation permutation for counts zero through five;
- the first 64 distinct frozen SplitMix permutations at counts six and seven;
- 10,000 deterministic CPU cases from state `0x9e3779b97f4a7c15`;
- the same 10,000 CPU/CUDA cases on each tile
  `1/31/32/255/256/1024`, for 60,000 tile-case executions;
- all eleven precedence rows and every reachable work-event kind;
- every hard dimension at `0`, `1`, `limit-1`, `limit`, `limit+1`, checked
  product boundaries, and overflow;
- maximal-depth, arena transition, malformed, and hostile cases;
- exhaustive v2 `UNSUPPORTED_VERSION` no-write combinations;
- every v2/v3 C/C++/ctypes size and field offset;
- two preflights and two fills with identical counts, fingerprints, payload,
  report, work ledger, and semantic hash;
- one-at-a-time mutation of every serialized input field;
- an independently complete exact-small candidate union and brute-force
  selection;
- exact oracle/native and CPU/CUDA outputs;
- exact semantic hash across Clang, GCC, MSVC, Apple, and Android;
- zero sanitizer, undefined-behavior, leak, race, crash, canary, resource, or
  nondeterminism finding.

Any missing campaign or one mismatch is unconditional NO-GO.

### Executable exact-small discovery

The first implementation of the frozen exact-small domain produces 9,024
valid cases and exact twice-replayed Clang/GCC hashes, but every case contains
zero canonical edges and therefore zero paths and entries. The cyclic
`detector_id` row prevents adjacent target matching; the only same-detector
gap has a frequency bound below the corresponding template separation.

This does not permit changing or replacing the frozen corpus. It remains the
mandatory ABI, canonicalization, permutation and fingerprint corpus. Final
admission additionally requires a separately versioned, independently audited
candidate-rich exact domain that proves non-empty family generation and
selection without receiving candidates from native code.
