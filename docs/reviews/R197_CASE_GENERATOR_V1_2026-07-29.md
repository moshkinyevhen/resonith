# R-197 Case Generator v1

Status: **FROZEN AUDIT INPUT**

This file freezes the finite oracle domain and deterministic randomized case
generator used by the R-197 transactional-analyzer gate.

## Exact-small domain

Use one resolution `{id=0, fft=128, hop=64}` at 48,000 Hz. For every
observation count `n` from zero through five, evaluate eight ordered template
families. Observation IDs are `0..n-1`; centers are `64*i`; frame indices are
`i`; every reserved field is zero.

For template family `f` and index `i`, select each field from the row by
`(i+f) mod row_length`:

- frequency Hz: `[0, 110, 220, 440, 1000, 12000, 24000]`, encoded Q20;
- frequency uncertainty Hz: `[0, 1, 1/2, 4]`, encoded unsigned Q20;
- phase turn: `[0, 0x40000000, 0x80000000, 0xc0000000]`;
- phase step: `[0, 0x10000000, 0x20000000, 0xffffffff]`;
- normalized amplitude Q16: `[1, 32768, 65536, 0xffffffff]`;
- amplitude uncertainty Q16: `[0, 1, 32768]`;
- phase uncertainty U31: `[0, 1, 0x40000000, 0x80000000]`;
- detector ID: `[-1, 0, 1]`;
- band ID: `[0, 1, 127]`;
- ownership component: `[0, 1, 2]`;
- ambiguity component: `[0, 1, 0xffffffff]`;
- flags: `[2, 3, 6, 7]`;
- protected rank, neighbour priority, potential and uncertainty penalty Q8:
  `[-256, 0, 256]`.

For each `(n,f,manifest)`, the independent R-190 oracle emits the one complete
canonical edge union required by the API. Enumerate every observation
permutation and require identical canonical payload, work trace and
fingerprint. The valid supplied-edge presentation is always ascending
`candidate_id`; every supplied-edge permutation other than identity is an
explicit invalid-input case. Missing, duplicate, extra and one-field-forged
edges are also invalid cases, never alternative valid graph subsets.

Evaluate four manifest families:

1. gaps `[1]`, neighbours `1`, cycles `[0]`;
2. gaps `[1,2]`, neighbours `2`, cycles `[-1,0,1]`;
3. gaps `[1,3]`, neighbours `16`, cycles `[0]`;
4. gaps `[1,2,4,8]`, neighbours `4`, cycles `[-1,0,1]`.

Frequency jump/slope pairs are `(0,0)`, `(1 Hz Q20,0)`,
`(0,1 Hz/sample Q20)`, and `(440 Hz Q20,1 Hz/sample Q20)` matched by manifest
family index. Path limits are set to the exact required values and tested again
at minus one and plus one. Cases with six and seven observations use the same
eight templates and four manifests, all observation permutations generated by
the first 64 distinct Fisher-Yates results from `R197-SPLITMIX64-1`, and the
same complete canonical-edge rule.

## Deterministic randomized generator

Generator ID is `R197-SPLITMIX64-1`. State update and output are:

```text
state = state + 0x9e3779b97f4a7c15 mod 2^64
z = state
z = (z xor (z >> 30)) * 0xbf58476d1ce4e5b9 mod 2^64
z = (z xor (z >> 27)) * 0x94d049bb133111eb mod 2^64
return z xor (z >> 31)
```

There is no rejection sampling. Every bounded choice is `next() mod N`.
CPU cases start at state `0x9e3779b97f4a7c15`; CPU/CUDA cases start at
`0xd1b54a32d192ed03`.

The CPU state is initialized once before case zero and continues across all
10,000 cases. For every CUDA tile size the state is reset to
`0xd1b54a32d192ed03`, so every tile evaluates the identical 10,000 logical
cases. The six/seven-observation permutation campaign resets state to
`0x6a09e667f3bcc909 XOR n XOR (f<<8) XOR (manifest_index<<16)` for each tuple.
Standard Fisher-Yates iterates `i=n-1..1`, draws exactly once, and swaps indices
`i` and `next()%(i+1)`; duplicate permutations are skipped without resetting
state until 64 distinct permutations exist.

For case `c`:

1. observation count is `2 + next()%95`;
2. sample rate is selected from
   `[8000,16000,24000,48000,96000,192000,384000]`;
3. one resolution is selected from
   `[(128,64),(256,128),(512,256),(1024,512)]`;
4. each observation uses ID `i`, frame `i`, center `frame*hop`;
5. frequency is `next() % (sample_rate/2 + 1)` Hz, encoded Q20;
6. draw once for each field in this exact order: frequency uncertainty, phase
   turn, phase step, normalized amplitude, amplitude uncertainty, phase
   uncertainty, detector ID, band ID, ownership component, ambiguity component,
   flags, protected rank, neighbour priority, potential, uncertainty penalty;
   each value is the named exact-small row at `draw % row_length`;
7. gaps are the ascending unique prefix selected from `[1,2,3,5,8,13,21,34]`
   with length `1+next()%8`;
8. neighbours are `1+next()%16`; cycle offsets are one of `[0]`,
   `[-1,0,1]`, `[-2,-1,0,1,2]`;
9. jump is `(next()%2001) Hz Q20`; slope is
   `(next()%9) / 8 Hz/sample Q20`;
10. remaining graph-manifest fields are fixed:
    `minimum_track_observations=2`, `continuation_base_bits_q8=256`,
    `continuation_reward_q8=256`, `score_saturation=2^62-1`,
    `maximum_path_hypotheses=1024`, `exact_set_candidate_limit=20`;
    path fields are fixed:
    `second_order_law_version=2`, `work_ledger_version=1`,
    `protected_band_count=1`, both per-state K values `8`, every top-K `128`,
    protected paths per band `2`, minimum path observations `2`, maximum path
    observations `n`, exact-set limit `20`, amplitude floor `1`, amplitude
    weight `1024`, frequency sigma floor `2^19`, birth cost `12288`, death cost
    `2048`, score saturation `2^62-1`; all protected-band uppers and reserved
    fields are zero;
    resource limits are exact requirements unless the boundary selector below
    changes one;
11. draw one boundary selector `b=next()%4`: zero uses exact requirements; one
    uses exact-minus-one only when exact is non-zero and otherwise uses exact;
    two uses checked exact-plus-one; three uses the caller hard ceiling. Draw
    one dimension selector across edge, path, entry, frontier, state, work,
    host bytes, device bytes and depth, and change only that dimension;
12. supplied canonical edges are produced by the independent arbitrary-
    precision oracle, then a selector chooses canonical, one-field forged,
    missing, duplicate, extra or permuted presentation;
13. draw `presentation=next()%6`: zero canonical; one XORs the low bit of field
    `next()%12` in edge `next()%edge_count` (or uses an extra edge when empty).
    The field index table is exactly:
    `[candidate_id, source_observation_id, target_observation_id,
    center_delta_samples, frequency_delta_hz_q20, gap_hops, cycle_offset,
    phase_error_u31, continuity_cost_q8, provisional_program_cost_q8, flags,
    reserved[0]]`; `struct_size`, `abi_version`, and `reserved[1]` do not
    participate in this selector;
    two removes the final edge (or adds one when empty); three appends a copy of
    the first edge (or adds one when empty); four appends an edge with
    `candidate_id=edge_count`, source ID zero, target ID `n-1`, center delta
    `(n-1)*hop`, all other scalar fields zero and valid ABI headers; five
    reverses the edge list when count exceeds one and otherwise uses the forged
    rule;
14. no generated invalid case is silently regenerated. Its expected first
    status follows the frozen precedence table.

The case manifest itself, not a language RNG library, is normative. A generated
JSONL evidence file records generator ID, initial state, case index, all logical
fields and expected first status. Its SHA-256 is published before the
implementation gate and checked by every platform job.
